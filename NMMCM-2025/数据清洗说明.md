# 马拉松经济高质量发展 - 数据清洗说明

## 数据清洗流程概述

本项目针对B题"马拉松经济的高质量发展思路探索"的数据进行了全面的清洗与处理，主要包括以下步骤：

1. **数据预处理**：对原始附件数据进行基础处理，转换格式并存储到`processed_data`目录
2. **数据清洗**：对预处理后的数据进行缺失值填充和异常值处理，结果存储到`processed_data/cleaned`目录
3. **数据质量测试**：对比清洗前后的数据，评估清洗效果

## 数据清洗内容

### 缺失值处理

针对不同类型的数据采用不同的缺失值处理策略：

1. **数值型数据**：
   - 使用中位数填充缺失值（相比均值，中位数对异常值更不敏感）
   - 对于时间序列数据，考虑使用前向填充或后向填充保持数据连续性

2. **分类型数据**：
   - 使用众数（最常见值）填充缺失值
   - 对于地理位置等关键字段，如果缺失则删除整条记录

3. **日期型数据**：
   - 使用前向填充和后向填充相结合的方式处理缺失日期

### 异常值处理

采用多种异常值检测和处理方法：

1. **Z-score方法**：
   - 计算每个值的Z分数，判断其与均值的偏离程度
   - 通常将|Z| > 3的值视为异常值

2. **四分位距(IQR)方法**：
   - 计算数据的第一四分位数(Q1)和第三四分位数(Q3)
   - 将低于Q1-1.5×IQR或高于Q3+1.5×IQR的值视为异常值

3. **中位数绝对偏差(MAD)方法**：
   - 计算每个值与中位数的绝对偏差的中位数
   - 对局部异常值检测效果更好

4. **异常值处理策略**：
   - Winsorizing（截尾）：将异常值替换为一定分位数的值
   - 移除：对于严重异常的数据直接删除
   - 限制法：将异常值限制在合理范围内

## 各数据集的具体清洗策略

### 1. 气象数据（附件1）

- **缺失值处理**：对temperature、wind_speed等字段使用中位数填充
- **异常值处理**：使用IQR方法检测异常气象数据，采用Winsorizing方法将异常值限制在5%~95%分位数范围内
- **数据类型转换**：将datetime转换为标准日期时间格式

### 2. 轨道交通客运量数据（附件2）

- **缺失值处理**：对客运量、运营里程等数值字段使用中位数填充
- **异常值处理**：对客运量等指标使用IQR方法检测异常值，采用截断方式处理
- **格式标准化**：统一城市名称格式，解决可能的编码问题

### 3. 人口普查数据（附件3）

- **缺失值处理**：对人口数据采用中位数或相邻地区均值填充
- **异常值处理**：对人口统计数据做合理性检查，异常增长率需特别关注
- **数据整合**：将不同普查年份的数据结构统一，便于纵向比较

### 4. 西安市基础数据（附件5）

- **缺失值处理**：
  - 对于坐标数据缺失的记录直接删除（对空间分析至关重要）
  - 对其他非关键字段采用适当的填充方法
- **异常值处理**：
  - 检查经纬度范围，确保在西安市区域内（经度约108-109.5，纬度约33.5-35）
  - 对评分等数值采用限制法处理异常值

### 5. 马拉松赛历数据（附件12）

- **缺失值处理**：对报名人数、完赛人数等关键字段采用中位数填充
- **异常值处理**：检查完赛率异常值（应在0-1之间），超出范围的值进行截断
- **日期标准化**：统一比赛日期格式，提取年份和月份信息

## 数据清洗效果评估

对清洗前后的数据进行对比分析，主要评估指标包括：

1. **缺失值减少率**：清洗前后缺失值数量的变化比例
2. **异常值处理量**：被检测并处理的异常值数量
3. **数据分布改善**：通过直方图比较清洗前后的数据分布变化
4. **关键统计量变化**：均值、中位数、标准差等统计量的变化情况

## 使用方法

项目提供了完整的数据清洗工具链，使用方法如下：

1. **运行完整数据处理流程**：

   ```sh
   python run_data_processing.py
   ```

2. **仅运行数据清洗**：

   ```sh
   from data_cleaning import DataCleaner
   cleaner = DataCleaner()
   cleaned_data = cleaner.clean_all_data()
   ```

3. **测试数据清洗效果**：

   ```sh
   python test_data_cleaning.py
   ```

## 清洗后的数据使用建议

1. 对于数据建模和分析，优先使用清洗后的数据（`processed_data/cleaned`目录）
2. 在进行探索性分析时，可对比原始数据与清洗后数据的差异，了解数据质量问题
3. 对于时间敏感的分析（如气象窗口期），建议结合原始数据进行交叉验证，确保清洗过程未引入偏差

## 数据质量说明

尽管经过了全面的清洗处理，使用者仍应注意以下事项：

1. 某些数据集可能存在结构性的缺失，如部分年份或城市的数据缺失，这种情况无法通过填充解决
2. 填充的缺失值和处理的异常值可能影响某些统计分析的精确性，特别是对样本量敏感的分析
3. 不同附件数据之间的整合可能存在城市名称不统一等问题，需在分析时注意
